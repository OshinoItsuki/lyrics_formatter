# 歌詞改行ツール

ニコカラ制作向けの歌詞整形支援ツールです。

RhythmicaLyricsで作成したタイムタグ付き歌詞を、ニコカラメーカーの
「空行位置にページ区切りを設定」機能で使用しやすい形式へ自動整形します。

---

## ダウンロード

最新版は **Releases** からダウンロードできます。

ZIPを解凍後、

```
歌詞改行ツール.exe
```

を実行してください。

---

## 主な機能

### 自動整形

タイムタグ付き歌詞を解析し、自動で空行を追加します。

* 基本設定では2行ごとに空行を追加
* 前後のタイムタグの時間差を比較し、必要な箇所には1行でも空行を追加
* 改行間隔・時間差閾値は任意に変更可能

時間差閾値は、ニコカラメーカーで設定している

* ワイプ前の表示時間
* ワイプ後の表示時間
* 歌詞の表示間隔

の合計値に合わせることを推奨します。

この設定にすることで、ニコカラメーカーの
「一定行数ごとにページ区切りを設定」と同等の動作になります。

---

## 自動割付

ニコカラメーカーへ読み込ませる前に、タイムタグと表示時間設定を使って行割付を計算します。

* 基準行数を優先して割付
* 基準行数では表示保護時間を維持できない箇所だけ行数を増加
* 設定した最大行数まで段階的に調整
* 最大行数でも不足する場合は、ニコカラメーカー相当の優先順位で表示間隔・ワイプ後・ワイプ前を削減
* 同じ表示枠へ入る行同士を比較するため、実際の字幕切り替えに近い判定
* ページ区切りと段落区切りを一覧で確認
* 「反映」を押すまで出力欄は変更しない

自動割付画面の「割付設定」から、次の項目を変更できます。

* 基準行数
* 最大行数
* ワイプ前の表示時間
* ワイプ後の表示時間
* 歌詞の表示間隔
* 表示保護時間
* ニコカラメーカー2／3の設定バックアップ（`.sta`）読み込み

自動整形用の改行間隔とは別に保存されるため、通常の自動整形設定には影響しません。

---

## 使い方

1. RhythmicaLyricsでタイムタグ設定済みの歌詞を作成します。
2. エディタモードで表示されるテキストをコピーします。
3. 歌詞改行ツールの入力欄へ貼り付けます。
4. 通常の一定行数整形は「自動整形」、表示時間を考慮した割付は「自動割付」を押します。
5. 自動割付では結果を確認し、問題なければ「反映」を押します。
6. 出力欄へ反映された歌詞は同時にクリップボードへコピーされます。

---

## 設定について

メイン設定では、通常の自動整形・タイムタグ検査・パート抽出に関する設定を変更できます。

自動割付専用の設定は、自動割付画面の「割付設定」から変更します。メイン機能の改行間隔とは独立して保存されます。

設定値はJSONファイルへ保存され、次回起動時に復元されます。

# タイムタグ検査機能

タイムタグの巻き戻りを検知します

デフォルトで行頭の巻き戻り(前行の終わりより早い場合)は無視する設定になっています

## 機能

前後のタイムタグを比較し、

時間が巻き戻っている箇所(後ろのタイムタグが前より早い) を検出します。

該当箇所はハイライト表示され、検査画面に行番号を表示します。

また、設定から

```
各行最初のタイムタグ違反は無視する
```

のON/OFFを変更できます。

---

# タイムタグ並び替え機能

設定でON/OFFを変更できます。

通常使用ではONのままで問題ありません。

自動整形実行時に、各行の先頭タイムタグを基準に昇順で並び替えます。

以下のような場合に便利です。

* 複数の歌詞データを結合した場合
* 後からコーラスパートを追加した場合
* タイムタグ順が崩れた場合

---

# パート分け抽出機能

歌詞に含まれるパート分け(男)などを抽出して中の文字を出力します。

()以外の文字でパート分けを囲っている場合は設定で指定してください。

また、コーラスも()で分けている場合、タイムタグを含んでいれば除外されます。

## 注意事項

本ツールはRhythmicaLyricsで作成したタイムタグ歌詞を対象に設計しています。

その他の形式の歌詞データでは正常に動作しない場合があります。
